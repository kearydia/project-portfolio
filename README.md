# 项目作品集

软件工程课程、竞赛和个人项目。每个压缩包包含项目源码、运行说明，以及项目所需的测试或示例材料。下载后解压，先阅读包内的 `README.md`。

| 项目 | 实现内容 | 源码包 |
| --- | --- | --- |
| **企业运营数据深度分析管理系统** | Java、Spring Boot、MyBatis、MySQL 和 Vue 3。支持客户与产品档案、多商品销售订单、图表、Excel 导出、角色权限和操作日志。 | [下载源码](./enterprise-ops-analytics.zip) |
| **实验算盘** | 离线大学物理实验数据处理工具，包含 27 个实验模板、异常值检查、拟合、误差分析和报告导出。 | [下载源码](./physics-experiment-assistant.zip) |
| **多平台电商对账助手** | 使用 Python 统一三平台订单字段，核对退款和支付净额，输出 Excel 工作簿、HTML 看板与 JSON 摘要。附模拟数据。 | [下载源码](./omnicommerce-ai.zip) |
| **Python 网络端口检测工具** | 使用 Python 标准库检查本机或获授权环境的 TCP 端口，支持结果汇总与 CSV 导出。 | [下载源码](./python-port-checker.zip) |
| **黄金时刻赛车** | 原创 Web 赛车项目，基于 TypeScript、Babylon.js 和 Havok，包含生涯赛、计时赛、轨迹回放和本地存档。音效及相应许可随包提供。 | [下载源码](./golden-hour-racer.zip) |

## 企业运营数据分析系统进度

当前是课程项目组内评审版。源码包附有 MySQL 表结构、虚构订单、接口说明和本地构建步骤。原评审版记录了 29 项 Java、MockMvc 与 MyBatis 相关测试通过。组员环境中的首次建库、角色隔离、导出对账和故障恢复仍在评审范围内。

## 测试

整理作品集时运行了实验算盘的 278 项测试、电商对账助手的 35 项测试、Python 端口检测工具的 52 项测试，以及黄金时刻赛车的 81 项测试，均通过。
